# 方向检查：视频拆解「读图腿」没有身份也没有失败原因（RW）· 2026-10-11

触发：`node scripts/fix-churn.mjs` 命中——`electron/video/` 近 14 天第 4 个 fix、`shotTable/` 目录第 6 个 fix、`streamTextTask.ts` 第 3 个 fix；自写登记 `ai-sdk-text-stack`（to-replace）30 天内第 5 个 fix。用户 10-11 走查第 1 条，且已在方案卡 §8 拍板「拆解这批一起修」。

## 0. 一句话根因

拆解的**读图这条付费腿由代码自动挑模型、结果只写日志**：用户既选不了、也看不到失败原话——音频腿 09-17 补过「可指定」，读图腿从没补，同一份 payload 里两条腿形状不一致。

## 1. 归类表

| 提交 / bug | 直接原因 | 类 |
|---|---|---|
| 09-17 转写腿绑在大脑那一家 | 腿的身份由代码隐式推 | 付费腿没有显式身份 |
| 09-11 每格「没读出」 | 失败被 catch 吞成空 | 失败原因没落盘 |
| 本次：全部镜头 429 | 默认挑中免费限流模型 + 3 次重试放大 + 原话只进日志 | 同上两类 |

## 2. 为什么会一直出现

表示层：`DeconstructVideoPayload` 里只有音频腿有 `{vendorKey, modelKey}`；所有权层：模型选择散在 `resolveTextBrainKeys`（自动）与 `resolveTranscribeLeg`（显式）两处；方向层：每次都在失败现场补，没人要求「每条付费腿都有显式身份 + 失败原话」。体验铁律：⑪「能选到」——入口缺失（footer 没有读图模型）。⑩⑫ 不适用。

## 3. 不改结构会冒出什么

| 预测 | 验证 |
|---|---|
| P1 下一条付费腿（如以后加 OCR / 音乐识别）又自动挑模型、失败进日志 | `rg "resolveTextBrainKeys" electron` 调用点数 |
| P2 别的 429 来源（供应商换个限流文案）仍被 SDK 重试放大 | `maxRetries` 在 `streamTextTask` 之外仍有默认 |

## 4. 靶子独立性

既有测试只测 prompt 构造与转写腿解析，**没有任何测试走过读图腿的模型身份与失败落表**——所以这一类一直没被拦。本次补编排级测试（必红先提交）。无「修对反而掉分」先例。

## 5. P0：这是我们独有的吗？现成方案

模型选择与「能不能读图」判定：现成的 `findExecutableModel` / `modelSupportsImageInput`（已在仓库）；重试策略：AI SDK 自带 `maxRetries` 参数——不自写重试。`ai-sdk-text-stack` 登记为 to-replace（`docs/plan/2026-10-01-tech-stack-line-0.24.md`）：本次**不加任何自写逻辑**，只传一个 SDK 已有的参数；栈替换归 0.24 线，不在本刀换。

## 6. 接入 / 补 / 重写 / 删 对比表

| 选项 | 做什么 | 代价 | 风险 | 推荐 |
|---|---|---|---|---|
| 接入现成方案 | 读图腿选模型复用现成选择器与 `maxRetries` | 小 | 低 | **推荐（就是本方案）** |
| 补 | 在失败现场再加分支（如遇 429 切模型） | 小 | 隐式切换会改变花费 | 否 |

| 删 | 删拆解里的读图 | 丢功能 | — | 否 |

## 7. 用户要权衡的核心

默认读图模型是「自动挑」还是「必须你选」——本方案取：保持自动挑（零摩擦），但**软偏好优先用你在 Agent 面板选的脑（若它能读图）**，底栏随时换，失败原话看得见；永不在失败时悄悄换别家。

## 补记（2026-10-11 真付费走查后）：表头总时长的浮点尾数

真付费走查发现表头显示「3 镜 1.9000000000000001s」。同一类根因的另一个实例：**派生量在显示层现算**——每行时长已落在 0.1 秒格子上（`shotTime` 是精度 owner），但几个格子点上的数相加会重新长出浮点尾数，而表头（`ShotTableNode`）自己 reduce 后直接插值。类：「精度 owner 只管存储的量，不管由它们派生的量」。补法（结构）：总时长收成 `shotTableTotalSeconds` 唯一出口，产出时按 `quantizeShotSeconds` 量化，表头只读它，不写 round、不自己 reduce；单测钉住 0.1 + 0.2 + 1.6。数门：其余秒数显示读 schema 已量化的值，storyboard 合计是整秒 `Math.round`，没有别处直接拼浮点秒。
