# 方向检查：选区快照省略时的读法指路

## 触发

真实模型抽样显示，选区快照的省略说明会改变 Agent 的下一步：画布节点已经有能读回完整选中节点的读法，但统一的“缩小或分批”提示把 Agent 引向了另一条路。快照专用量具还把问题写成了自证式的固定回答，因此不能代替真实行为验收。

## 根因

发送时快照和实时画布读法各自表达同一批选区，却没有一个按类型声明“看不全时去哪读”的单一来源。于是模型把画布的省略当成不可恢复，用户被要求手动分批；时间轴片段和素材仍没有带选中标记的读法，继续需要用户缩小或分批。

## 决定

省略说明按 `omittedByKind` 中实际出现的类型派生：画布节点指向无参数的 `look_at_canvas`，说明节点行带有选中标记、可读到全部选中节点，并要求比较它报告的选中数与快照 `total`；数量不同就告诉用户发送后选区发生了变化。没有带选中标记读法的类型保留“请用户缩小选区或分批发送”。类型到读法的表只放在快照模块旁边，说明文字和投影预算长度都从它生成，避免模型面 schema 继续膨胀。

快照专用档删除。快照账由共享投影单测固定，真实模型量具只保留画布读法的主档；零花费演练只证明主档能跑通，不把夹具对固定答案的自证当成 Agent 行为证据。

## 拍板

用户原话：「#1263 选 A（画布看不全让 Agent 调 look_at_canvas 读全，时间轴/素材仍请用户缩小）」。
