## 为什么做

用户 10-10：中英文教程「急需」。已拍板：Astro Starlight，中文 `/docs`、英文 `/en/docs`，Pagefind 搜索；核心约 15 页（开始 2 / 画布 3 / 视频节点 4 / Agent 2 / MCP 3 / 快捷键 1）；每页一句价值 + 真实界面的截图和短动图。本段只做框架接入、门岗打通和 5 页样板（认识 Nomi、第一个作品、MCP 三页）+ 首页；其余 10 页第 2 段。

## 接入方案落地（对照 R-docs-framework 第六节 1–8 条）

1. **孤儿清理**（先修）：`build-marketing-site.mjs` 的「应有页面」集合改读全部页面（含教程页）。红绿证明：把清单挪走，`--check` 立刻报 5 个教程页是孤儿。
2. **sitemap 与页面清单**：`sitePages()` 并入 `docsPages()`；`/docs`、`/en/docs` 归「库首页」一档。`site.page-list` 概念登记已补说明。
3. **描述门岗**：判据不改。`Head.astro` 补 `twitter:description`、og 图、robots；canonical / hreflang / og:url 去掉 Starlight 在 file 格式下带的 `.html`。
4. **`check:site`**：新增两项：`docs-site (tests)`、`marketing docs`（重建一遍和入库产物逐字比对）。
5. **SEO 巡检**：`docs/seo/config.json` 的 `publicPaths` 是手写短清单，本段不改；巡检已读 sitemap（含教程页）。
6. **`_headers`**：加 `/_astro/*`（immutable）与 `/pagefind/*`（必须重新验证）。
7. **工作流**：不用改。`build-marketing-docs.mjs` 自己按 `marketing-docs/pnpm-lock.yaml` 冻结安装依赖（已装则跳过），所以 `site-data-sync.yml` 里的 `pnpm run build:site` 和 CI 的 `check:site` 都不需要多一步安装。
8. **不改 `wrangler.json`**；教程动图用 webm，不走 `run_worker_first` 的 mp4 规则。

## 实测补充（R-docs-framework 第九节未验证项）

| 项 | 结果 |
| --- | --- |
| 代码块复制按钮是否零配置 | 是。产物里每个代码块带复制钮（Expressive Code 默认） |
| 默认颜色模式是否跟随系统 | 是。浏览器 `prefers-color-scheme` 切换后主题随之切（亮 / 暗两张截图可证），顶栏另有手动「自动 / 亮 / 暗」 |
| `Head` 覆盖后 `twitter:description` 能否按页输出 | 能，门岗已核每页 og / twitter / meta 三者一致 |
| `format: file` + `trailingSlash: never` | 产物是 `docs/x.html`、`docs.html`；canonical 默认带 `.html`（与门岗冲突），Head 覆盖去掉；站内链接默认带 `.html`，胶水统一去掉（`check-site-links` 守） |
| sharp 在 Windows 上 | 本方案不用 `astro:assets`，不依赖 sharp |
| Astro 7 构建时长 | 13 页约 6 秒（本机） |
| 额外发现 | `shamefully-hoist=true`（`marketing-docs/.npmrc`）必需：Starlight 的 `Steps` 会把 markdown 解析器（带平台原生包）打进预渲染块，pnpm 默认布局下找不到平台包；另 Astro 用 rename 搬产物，输出目录必须和项目同盘，所以暂存放在 `marketing-docs/dist/` |

## 截图与动图（可重跑）

`node tests/ux/docs-media.record.mjs [--locale=zh-CN|en|all] [--only=名字,…] [--theme=light|dark]`：起仓库现有的隔离走查实例（`launchCoreSmoke`），夹具项目里的图和视频是仓库登记的真 AI 镜头；假主目录只给被测进程，用户真实资料一个字节不碰；窗口在屏幕外；标注框截前插入、截完删除。产出 `marketing/docs-media/<语言>/*.png|webm`，入库。界面变了重跑即可。
