## ★1 用户怎么用

当我在画布上给一个视频 / 图片节点配生成框，我想一眼看清「放了哪些参考、按什么方式发」，以便不用读说明就知道会发出什么。

1. 点选节点 → 生成框在下面；参考行一排 40px 小图（平时干净）；
2. 悬停小图 → 出名字 + 来源，停满 0.45 秒 → 右边出大图；× 才出现；
3. 提示词里引用显示「小图 + 名字」；
4. 点参数摘要 → 面板顶部切「参考 / 首帧 / 首尾帧」；首尾帧两格可对调，别的方式里放的图淡显「未用到」，切回来还在；
5. 模型菜单只列模型；同模型多家直接点小签；渠道缺方式时行尾一句小字带链接；
6. 换模型 / 改参数 / 加参考全部在这一件组件里；分镜行、列表详情、错误报告、Agent 输入框复用同一件。

**不做**：付费卡 D2（下一个 PR）；模型菜单里「不支持当前方式的模型名下写小字」（画布评论 10-18 已去掉）；错误点名参数在摘要里标红（见格 6）；粘贴图片 / 拖画布结果进参考框（census BOUND-01/02，本来就没有）。**已知坑**：生成钮 tooltip 写「生成（Enter）」是用户拍板的文案，但提示词里按 Enter 现状是换行、没有绑定生成——文案与按键不符，已报协调裁决（接键或改文案），本 PR 没有虚构快捷键。
**真实任务**：① 一个视频节点接两张连线图 + 上传一张，提示词引用其中两张，换到首尾帧再切回；② 图片节点加参考、换模型；③ 模型不收参考图的图片节点（Imagen 4）。都在真 Electron 里走过（`tests/ux/composer-b3-real.walk.mjs`，隔离资料目录，不点生成）。
**指标与量具**：主指标 = 30 张参考下三个操作到可见反馈（`composer-open-params-refs-30` / `composer-hover-ref-preview-30` / `composer-switch-mode-refs-30`）；质量指标 = 清单 65 个元素的走查断言（`composer-b3.walk.mjs` 100 条 + `composer-b3-real.walk.mjs` 60 条）；护栏 = 旧数据不丢（`composerLegacyData.test.ts`）、现有 `reference-entry` / `reference-row-alignment` / `asset-tile-badges-visible` 仍绿。

## ★3 一致与复用

一件 `AssetTile`（40px、悬停 ×、小提示 + 大图）供画布、分镜参考条、文本节点入口；一件 `AssetReferenceButton`（`iconOnly` 开关）供画布与 Agent；一件 `AssetInlineReference`（上下文给名字）供画布、分镜、Agent；参数面板 / 模型菜单 / 摘要钮是现有 `InlineParameterBar`（不改形态，只多传 `modeChoices`）。没有复制一份长得像的。顺手修的根因：实验室 `installCatalogBridge` 只装桥不种缓存，节点生成框相关的老基线其实都停在「没有可用模型」——现在种缓存。

## ★7 性能

①新增 / 改动的操作：选中节点出生成框（参考行变化）、悬停参考小图、点参数摘要开面板、面板里切生成方式（切方式会搬参考）、换模型。
②最坏规模：参考行 30 张图（Seedance 2.5 参考上限 30 图）。
③预算：默认（操作到可见反馈 ≤100ms，p95 ≤150ms，长任务 0）。
④场景（无头 Chromium 里真组件 + 真鼠标，共用 `responseTimer`；**不是**打包后的 Electron——Electron 夹具项目没有可用模型目录，生成框里没有参考数组，量不到参考行，2026-10-19 试过）：

| 场景 id | 中位数 | p95 | 预算 | 5 次，win32 i9-13900H |
|---|---|---|---|---|
| `composer-open-params-refs-30` | 46.9ms | 47.4ms | 100ms | ok |
| `composer-hover-ref-preview-30` | 27.5ms | 28.3ms | 100ms | ok |
| `composer-switch-mode-refs-30` | 64.0ms | 101.4ms | 100ms（p95 默认上限 150ms） | 中位 ok；p95 略超 100、仍在 150 内；长任务 p95 1 个 |

「选中节点 → 生成框出现」沿用现有 10 个 `canvas-select-composer-*` 场景（没改量具）；Electron 整机上它们量的是「无模型」的生成框，不含参考行——这是本 PR 量不到的部分，写在报告「未做完」。
