## ★1 用户怎么用

当我在画布上给一个视频 / 图片节点配生成框，我想一眼看清「放了哪些参考、按什么方式发」，以便不用读说明就知道会发出什么。

1. 点选节点 → 生成框在下面；参考行一排 40px 小图（平时干净）；
2. 悬停小图 → 出名字 + 来源，停满 0.45 秒 → 右边出大图；× 才出现；
3. 提示词里引用显示「小图 + 名字」；
4. 点参数摘要 → 面板顶部切「参考 / 首帧 / 首尾帧」；首尾帧两格可对调，别的方式里放的图淡显「未用到」，切回来还在；
5. 模型菜单只列模型；同模型多家直接点小签；渠道缺方式时行尾一句小字带链接；
6. 换模型 / 改参数 / 加参考全部在这一件组件里；分镜行、列表详情、错误报告、Agent 输入框复用同一件。

**不做**：付费卡 D2（下一个 PR）；模型菜单里「不支持当前方式的模型名下写小字」（画布评论 10-18 已去掉）；错误点名参数在摘要里标红（见格 6）；粘贴图片 / 拖画布结果进参考框（census BOUND-01/02，本来就没有）。**已知坑**：生成钮 tooltip 写「生成」是用户拍板的文案，但提示词里按 Enter 现状是换行、没有绑定生成——文案与按键不符，已报协调裁决（接键或改文案），本 PR 没有虚构快捷键。
**真实任务**：① 一个视频节点接两张连线图 + 上传一张，提示词引用其中两张，换到首尾帧再切回；② 图片节点加参考、换模型；③ 模型不收参考图的图片节点（Imagen 4）。都在真 Electron 里走过（`tests/ux/composer-b3-real.walk.mjs`，隔离资料目录，不点生成）。
**指标与量具**：主指标 = 30 张参考下三个操作到可见反馈（`composer-open-params-refs-30` / `composer-hover-ref-preview-30` / `composer-switch-mode-refs-30`）；质量指标 = 清单 65 个元素的走查断言（`composer-b3.walk.mjs` 100 条 + `composer-b3-real.walk.mjs` 60 条）；护栏 = 旧数据不丢（`composerLegacyData.test.ts`）、现有 `reference-entry` / `reference-row-alignment` / `asset-tile-badges-visible` 仍绿。
