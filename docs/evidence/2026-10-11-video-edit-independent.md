# 视频截帧与剪辑：独立验收

验收线：`/root/clip_review`，与实现线 `/root` 分离。日期：2026-10-11。

## 结论与证据边界

**本轮剪辑的设计对账、代码复审与已产出的 macOS Electron 走查证据通过，未发现剩余阻断。** 当前截帧双语复跑及 32 视频画布结构回归由主线进行，其最终结果须另行补充；本报告不提前给这两项通过结论。

本线亲自执行过前期浏览器样张验收，并向实现线报告了预览选区、Esc、只读权限、来源身份、独立宿主等问题；最终生产阶段亲自阅读源代码、测试实现、运行日志、性能 JSON，并逐张查看了下列六张生产截图。为避免干扰主线性能测量，本线**没有另起 Electron，也没有亲自重跑生产走查**。下文的 9/9 是对现存日志和测试方法的独立审计，不冒充第二次独立执行。

## 真实 Electron 证据审计

已阅读 `tests/ux/video-clip-direct.walk.mjs` 和 `.tmp/video-clip-walk.log`、`.tmp/video-clip-walk-en.log`。两份日志分别结束于 **9/9 passed (zh)**、**9/9 passed (en-dark)**。脚本使用 `launchNomiApp`、隔离项目/资料目录和生产构建，没有把浏览器设计实验室替代成生产功能。

| 覆盖 | 验证方法 |
|---|---|
| 打开、连续拖动、选区反馈 | 真鼠标按下/移动/松开；按住期间读 range 值，验证变化超过1.5s，避免“只动0.4s也算通过”。 |
| 选区播放 | 点原卡播放，采集播放时间，确认位于入出点之间，播放结束按钮返回播放态。 |
| 真实导出 | 本机 FFmpeg 产物；解析文件时长，误差≤0.25s；读取首帧像素反推源时间，误差≤0.15s；同时检查结果卡、来源边和来源 metadata。 |
| 原视频不改 | 导出前后源文件 SHA-256 一致。 |
| 撤销 | 一次 Ctrl+Z 同时移除派生卡和来源边。 |
| 处理中取消 | 150s 素材，等待真实百分比进度后点击取消；检查卡、边和项目内新增 trim 文件均移除。该测试没有独立枚举残留 FFmpeg 进程。 |
| 真实失败与重试 | 播放器缓存后移动实际源文件，使 FFmpeg 真实失败；恢复文件，重试同一张卡；验证产物非空且错误 UI 消失。 |
| 缩放、键盘、真实素材 | 50% 下真拖并导出；真实 1080p15s 素材三轮左右拖动及方向键；随后真实导出并核对时长。 |

脚本中保留的“readouts”函数名指读取原生手柄数值和时长，不代表界面仍有已被用户删去的数字输入。部分测试名称仍带旧术语，本报告按实际断言解释。

## 性能观测

直接读取：[中文 JSON](video-trim-production/performance-zh.json)、[英文深色 JSON](video-trim-production/performance-en-dark.json)。机器为 darwin arm64、Apple M5、24GiB；场景为真实1080p15s素材、4张源视频卡，每轨3轮。页面探针记录 rAF、键盘事件到面板变更后的帧、长任务、挂载播放器和组件渲染计数。

| 观测 | 中文三轮 | 英文深色三轮 |
|---|---|---|
| rAF 间隔 p95 | 9.4 / 9.1 / 10.3ms | 9.4 / 9.4 / 9.7ms |
| 键盘输入至下一帧 p95 | 8.3 / 8.4 / 8.2ms | 8.4 / 8.3 / 7.7ms |
| 长任务 | 均为0 | 均为0 |
| 其他节点重渲数 | 1 / 0 / 0 | 1 / 0 / 0 |
| 全页面最多挂载 video | 2 / 1 / 1 | 2 / 1 / 1 |

这些数字支持“本机四源卡场景连续操作顺畅”的有限结论。首轮确有另一节点重渲及第二个 video，不能写成所有轮次均零连带重渲/全页面唯一 video；当前记录不足以确定这两项的原因。面板本身没有第二预览的结构断言另行通过。

六轮 `maxPlaying=0` 是暂停状态下的拖动/键盘测量，不是“同时播放限制”有阳性对照的证明。后者应依据主线独立的32视频结构回归。当前没有改前对照、冷胶片生成延时、导出耗时对比、真实画面解码呈现延时或大画布性能结论；`inputToFrameP95` 也不能当作“输入到视频新帧解码完成”。不外推到 Windows 或所有硬件。

## 代码复审与已修正问题

- 会话由 `BaseGenerationNode` 按 node id 与来源 URL 挂载；来源替换会重建播放/编辑状态，避免旧播放时间与新素材身份混用。
- 会话 `writable` 在截帧函数内部强制检查，原卡只读状态仍可播放但不可截帧；只读浮条不暴露写入动作。
- 播放守卫仍保留懒挂载、metadata preload、自愈及唯一播放策略；编辑态阻止 hover 离开复位。
- 原卡控件放行 Esc，独立 videoDepth 实验室宿主已补会话 Provider。
- 手柄连续拖动门使用 metadata `readyState>=1`；解码中的 readyState 波动不再禁用手柄。相机和上方导出保留 decoded/seeking 检查。原先拖动被禁用打断的问题由主线真实走查发现并修正，复跑日志通过。
- Panel 每次变更同步写 `selection.current`；上方执行按钮读取这份选区并同步发起 `startVideoTrim` 后才关闭 Panel。未发现“先清选区再导出”或旧 React state 导出的顺序问题。
