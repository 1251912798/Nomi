## 确认连上了

先确认 Nomi 开着，再回到刚接好、并且已经重启过的助手，发这一句：

> 列出 Nomi 里现有的项目。

回复里出现了你 Nomi 项目库里的真实项目名，就算连上了。

接着可以试卡片上给的那句示例：

> 在 Nomi 新建项目「咖啡广告」，拆 3 个镜头加到画布，用我的图模型把第一个生成出来。

回到 Nomi，项目库里多了一个项目，画布上有镜头，就说明助手真的在操作 Nomi。如果助手要生成，请先确认你已经在 Nomi 里接好了模型。

## 连不上时

| 你看到的 | 多半是因为 | 怎么办 |
| --- | --- | --- |
| 助手说连不上 Nomi，或者没有 Nomi 的工具 | Nomi 没开；或者接入之后助手没有重启 | 先打开 Nomi，再把助手完全重启一次 |
| Nomi 的连接卡里没有我的助手 | Nomi 没在这台电脑上检测到它 | 装好助手再回来；或者用卡片最下面「其他客户端」的通用配置手动接入 |
| 点「一键接入」被拒 | 助手的配置文件不是合法 JSON、是只读的，或者里面叫 `nomi` 的那一条不是这个 Nomi 写的 | 照卡片上的提示处理：修好那个文件；取消只读；或者在助手里删掉那条 `nomi`，再回来接入 |
| 卡片提示「接入配置需要更新」 | 助手里写的是旧版本 Nomi 的启动方式，已经不在了 | 点卡片上的「升级接入」或「修复接入」，再重启助手 |
| Cursor 只能出草稿，不能直接制作 | Cursor 默认不是可信发起方，开关是关着的 | 在卡片里选中 Cursor，打开「允许 Cursor 自动发起制作」；并留意 Cursor 第一次调用时自己的确认 |

:::note
升级 Nomi 之后，卡片顶部可能会问你要不要把某个助手改成更快的连接方式。改之前 Nomi 会先备份；选「以后再说」也照样能用到下个版本。改完以后，用之前必须先打开 Nomi。
:::

## 还是不行

写下你用的是哪个助手、做到哪一步、助手原话怎么说，到 [GitHub 讨论区](https://github.com/aqm857886159/Nomi/discussions)问。不要把配置文件里的内容整段贴出来。
